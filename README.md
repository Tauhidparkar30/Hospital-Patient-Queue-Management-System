Hospital Patient Queue Management System

A Python-based Hospital Patient Queue Management System developed as a learning project to understand data structures and Python programming.

Features

- Patient registration
- Unique token number generation
- Emergency and normal patient queues
- Priority-based patient processing
- Doctor allocation
- Appointment date and time recording
- Patient booking cancellation
- Consultation status tracking
- Patient record management

Concepts Used

- Python
- Lists and Dictionaries
- Tuples (in earlier development)
- FIFO Queue
- Functions
- Conditional Statements
- Loops

Project Progress

- Phase 1: Basic Patient Queue Management
- Phase 2: Patient Information and Token Generation
- Phase 3: Emergency Priority Queue
- Phase 4: Doctor Allocation and Consultation Tracking

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

python project.py
